Key findings

No app owns more than one corner of the market

Each leader is great at one thing

Todoist leads capture, Sunsama leads daily rituals, OmniFocus leads depth, Tiimo leads wellbeing and Linear leads speed. Nobody combines them without ClickUp-level bloat.

Overdue guilt is the #1 reason people quit

Backlogs rot, red counts pile up and users declare “TODO bankruptcy”. A 1,402-point Hacker News thread ended with many going back to a .txt file.

Tasks still don’t know about time

Most list apps can’t tell you that you planned 9 hours into 4 free ones. Planners that can charge $15–34 a month.

AI earns its keep in capture and planning

Todoist Ramble got 76k users in 3 weeks. AI chatbots, credit metering and AI-justified price rises get backlash.

MCP is now table stakes

Todoist, TickTick, Sunsama, Akiflow, Notion, Linear, Asana and ClickUp all expose tasks to AI agents. What’s missing: scoped permissions, an activity log and undo.

Trust is a feature

Height and Clockwise shut down and deleted data, Motion pivoted to SMB, Amie became a note-taker. Local-first storage, export and fair pricing now differentiate.

What we should build

Seven pillars for Personal Work Management

A calm, fast personal work manager that knows your time. Todoist-grade capture, Sunsama-grade rituals and OmniFocus-grade depth that stays hidden until you switch it on. Agent-ready, local-first, fairly priced.

Guilt-free planning loop

  • Daily reset: each overdue task → Today / Reschedule / Someday / Drop
  • Separate do, due and start dates; start dates hide tasks
  • “Too hard right now” defer; auto-age stale tasks to Someday
  • Guided morning plan and evening shutdown

EvidencePain point #1; Sunsama’s ritual; start-date requests

A Today that knows your time

  • Estimates vs calendar free time with overload warning
  • Two-way Google, Outlook and CalDAV sync; drag to time-block
  • Auto-schedule that previews, lets you lock blocks and says why it moved something
  • One-click “re-plan the rest of today”

EvidencePain point #4; Motion/Reclaim complaints; Akiflow and Morgen patterns

Capture everywhere

  • Natural-language quick add with Todoist-level syntax
  • Voice brain-dump → multiple structured tasks
  • Email-in, share sheet, global hotkey, widgets, Watch
  • Commitments inbox from Gmail, Slack, GitHub, Jira, Linear — triage, then link back

EvidenceRamble’s adoption; fragmentation pain point

Depth you switch on

  • Marvin-style modules with methodology presets (GTD, Eisenhower, 1-3-5, Kanban)
  • OmniFocus-style availability and perspectives, on every platform
  • Visual query builder that round-trips to text
  • Explainable priority: “why is this #1?”
  • Guided weekly review with stalled-project detection

EvidenceSetup fatigue; OmniFocus is Apple-only; Taskwarrior urgency

Agent-ready, AI that plans

  • First-party MCP server, public API, CLI from day one
  • Scoped agent permissions: read-only or propose-then-approve
  • Agent activity log with undo
  • AI breaks down tasks, estimates, drafts the weekly review — opt-in, labeled, included in the price

EvidenceMCP now expected; AI-fatigue and credit backlash

Trust by design

  • Local-first speed: no spinners, full offline
  • Optional end-to-end encryption, metadata included
  • Continuous Markdown / JSON export and a written exit guarantee
  • Fair pricing: real free tier, ~$5/mo, optional buy-once local licence

EvidenceHeight and Clockwise data deletion; price-hike backlash

Focus & wellbeing

  • Focus timer tied to tasks, estimate vs actual time
  • Habits on the same task objects
  • Low-density ADHD mode: one-thing-now view, visual countdowns, forgiving streaks
  • Widgets, Live Activities and an optional companion

EvidenceTiimo, Structured, Finch retention, Focusmate’s ADHD share
